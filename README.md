# Dados de exemplo do CineTag

Este repositório contém o arquivo `db.json`, com a coleção `videos` usada pelo projeto [CineTag](https://github.com/GuilhermeSerafim/cinetag).

Cada entrada tem `id`, `titulo`, `capa` e `link`. O arquivo contém quatro registros de exemplo, com imagens externas e links de incorporação do YouTube. São dados de exemplo para o estudo, não uma API de produção ou serviço próprio de streaming.

A página inicial do frontend referencia o endpoint `https://my-json-server.typicode.com/GuilhermeSerafim/cinetag-api/videos`. Este repositório não contém manifesto, código de servidor ou comandos de inicialização; o endpoint depende de serviço externo.

O README do frontend atribui o estudo ao [curso React da Alura](https://cursos.alura.com.br/course/react-praticando-react-js).
